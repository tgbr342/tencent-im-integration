## 接入准备：创建应用，获取 SDKAppID 和密钥

腾讯云IM不需要自己搭建消息服务器。注册腾讯云账号后，在控制台创建即时通信应用，会得到 SDKAppID 和密钥。应用创建后默认是体验版，100 个用户以内不花钱。

SDKAppID 是应用标识，客户端初始化时要传入；密钥用于签发 UserSig，也就是登录凭证。UserSig 要在服务端生成，密钥不能打进客户端安装包——安装包一旦被反编译，别人拿着你的密钥就能冒用应用身份。

## TUIKit 和 IM SDK 选哪个

想要现成的聊天界面，选 TUIKit；要完全自定义界面，选 IM SDK。前者是含 UI 的组件库，会话列表、聊天窗口、联系人页面都是现成的，还支持修改主题、自定义消息类型和自定义表情；后者是纯能力层，初始化、登录、收发消息、会话、群组、资料管理这些接口都在，界面要自己写。

平台覆盖两边一致：Android、iOS 与 Mac、Web 与小程序与 uni-app、Flutter、Unity、Windows C++、C 接口、React Native、Electron。做跨端产品的话，基本不用为“某个端没有 SDK”发愁。

TUIKit 还有一层实际好处：离线推送、消息已读回执、对方正在输入、本地搜索这些功能都有现成封装，不用从零开始接。

## 跑通第一条消息：初始化、登录、收发的完整流程

按官方文档的模块顺序走，一条消息从发出到显示在对方屏幕上，中间是这么几步：

1. 初始化。应用启动时初始化 SDK，传入 SDKAppID。
2. 登录。用用户 ID 加上服务端签发的 UserSig 登录。
3. 发送消息。单聊指定对方用户 ID，群聊指定群 ID。文字、图片、短语音、短视频都支持，也可以自定义消息类型。
4. 接收消息。注册消息监听器，新消息到达时触发回调，更新界面。
5. 会话列表。拉取最近会话展示在消息页，未读数、最后一条消息、置顶都在这个模块里处理。

再往下走，会陆续用到历史消息（漫游）、消息扩展、已读回执、群组管理这些模块。已读回执属于旗舰版才有的高阶能力，体验版和专业版用不了，这一点文档不会写在最显眼的位置。

## 群组、资料、离线推送对应哪些模块

群组相关的需求集中在两个模块：群组管理负责建群、解散、群资料、群公告，群成员管理负责邀请、踢人和设置管理员。用户资料模块管昵称、头像和自定义字段；好友关系、黑名单、好友验证属于关系链模块。

离线推送需要单独接。App 退到后台后要收到通知，得接入消息推送插件，再配置各手机厂商的推送通道。推送晚到、收不到，多数时候是厂商通道配置的问题，跟 IM 本身没关系。

如果业务涉及内容安全，云端审核覆盖全部场景、全部消息类型的审核，接入前先配置好审核策略。

## 上线前容易踩的坑：配额、漫游和未读消息规则

上线前最容易踩的坑集中在三处：版本配额、漫游时长和未读消息规则。这几条官方文档里都有，但散在不同页面，接入时很容易漏。

漫游消息时长按版本走：体验版和专业版 7 天，旗舰版 30 天，企业版 90 天。超过漫游期的消息，本地 SDK 里还在，但换设备登录就拉不到了。控制台可以延长漫游时长，属于增值服务，单独计费。

未读消息的规则更细。单聊未读消息默认保存 7 天，每个用户最多保存 250 个单聊会话的未读消息，每个单聊会话最多保存 100 条；超出的部分不计入未读计数，但消息本身仍存在漫游里。群聊没有这些条数限制。做消息列表红点时，这几个数字直接决定你最多能显示多少。

最近联系人默认存 100 个，超过 7 天没有新消息的联系人会从列表里消失。如果你打算用最近联系人来驱动会话列表，要先把这条规则考虑进去。

还有一条前面提过的：开发版到期直接停服。拿开发版当长期测试环境，到期当天服务就停了，不会自动降级到体验版。账号下有付费基础套餐时才能手动续期，每次续一个月。

## 常见问题

**腾讯云IM免费吗？**
有免费版本。体验版 0 元、无到期时间，限制 100 个用户；开发版也是 0 元，但只有一个月有效期。

**什么时候必须升级付费版？**
用户数超过 100 就必须升级，因为体验版和开发版都限制 100 个用户。

**支持哪些客户端平台？**
Android、iOS 与 Mac、Web 与小程序与 uni-app、Flutter、Unity、Windows C++、C 接口、React Native、Electron。

**消息能保存多久？**
服务端漫游按版本 7 到 90 天不等；SDK 默认不删除本地消息，除非你主动调用删除接口。

**需要自己部署服务器吗？**
消息收发走腾讯云，不需要自建。但账号导入、UserSig 签发这类管理操作，通常由你的服务端调用 REST API 完成，第三方回调也是接到你的服务端地址。
